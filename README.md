# Projeto Produto

Aplicação Angular para criar, listar, editar e excluir produtos.

## Funcionalidades
- Criar novos produtos
- Listar produtos criados
- Editar informações de um produto
- Excluir produtos
- Navegação simples entre as telas

## Tecnologias
- Angular
- TypeScript
- RxJS
- Angular Router
- HttpClient
